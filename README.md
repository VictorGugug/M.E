# M.E - ZarXP

ZarXP is the principal project. Real Windows XP recreated for the web, pixel perfect.

## Principal

- ZarXP/ - React 19 + Vite 8 + Zustand - http://localhost:5173
- .github/workflows/deploy-zarxp.yml - GitHub Pages deploy

`ash
